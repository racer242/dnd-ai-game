# ⚔️ AI D&D Master + Яндекс Музыка плеер

Двунаправленный проект: **AI-мастер для D&D** в консоли VS Code и **скрипт для управления Яндекс Музыкой**, который создаёт музыкальное сопровождение к игровым сессиям.

Сюжет, персонажи, мир — всё создаётся динамически перед началом кампании через диалог с AI-мастером.

---

## 1. Описание проекта

### 1.1. AI D&D Master

AI-мастер работает в консоли VS Code как текстовый ведущий. Он:

- Генерирует сюжетную линию по запросу игрока
- Создаёт персонажей через пошаговый диалог
- Ведёт игровые сессии: описывает сцены, обрабатывает действия, применяет правила D&D 5e
- Сохраняет всё состояние в файлах (сюжет, персонажи, прогресс сессии)
- Управляет NPC, врагами, боями, проверками навыков
- Адаптирует сценарий под действия игрока

**Принципы работы:** мастер беспристрастен, честен, не спасает персонажей от последствий, не подстраивает мир под партию. Мир живёт своей жизнью.

### 1.2. Структура проекта

## 2. Как играть в D&D

### 2.1. Старт кампании

Вся игра идёт в диалоге с AI-мастером в консоли VS Code. Порядок действий:

1. **Создать сюжетную линию** — мастер генерирует кампанию, разбивает на хроники, определяет антагонистов
2. **Создать персонажа(ей)** — пошаговый диалог: роль, раса, класс, характеристики, имя, биография
3. **Начать сессию** — мастер описывает начальную сцену и спрашивает: «[Персонаж], что делаешь?»

Пример старта:

```
Создай главную сюжетную линию
Создай персонажа
Стартуй игровую сессию
```

### 2.2. Формат игры

Мастер описывает сцену, игрок говорит, что делает персонаж, мастер обрабатывает действие и описывает результат:

```
═══════════════════════════════════
СЕССИЯ 1 НАЧАТА
═══════════════════════════════════

[Описание места, атмосферы, NPC]

Дариус, что делаешь?
```

### 2.3. Команды управления

| Команда                            | Действие                           |
| ---------------------------------- | ---------------------------------- |
| `Создай главную сюжетную линию`    | Генерация кампании                 |
| `Создай персонажа`                 | Пошаговое создание персонажа       |
| `Стартуй сессию`                   | Начать новую игровую сессию        |
| `Продолжаем`                       | Продолжить прерванную сессию       |
| `Показать состояние партии`        | Статус: HP, ресурсы, локация       |
| `Показать цели сессии`             | Текущие квесты                     |
| `Закончить на сегодня`             | Сохранить и выйти                  |
| `Загрузить обновлённого персонажа` | После ручного редактирования файла |

### 2.4. Боевая система

В бою учитывается:

- **Action** — основное действие (атака, заклинание, рывок и т.д.)
- **Bonus Action** — бонусное действие (если есть способность)
- **Movement** — перемещение (30 футов по умолчанию)
- **Reaction** — реакция (провоцированная атака, counterspell и т.д.)
- **Ресурсы** — ходы, ячейки заклинаний, патроны, зелья, способности

Мастер применяет правила **D&D 5e** беспристрастно:

- Броски соответствуют сложности
- Враги действуют по своему интеллекту и мотивации
- Смерть персонажа возможна
- Результаты бросков честны и не корректируются

### 2.5. Сюжетная структура

Кампания строится по принципу **хроник** — отдельных adventure-арок, логически связанных в единую сюжетную линию:

- 5–6 хроник на кампанию
- 2–4 сессии на хронику
- Каждая хроника имеет локальную задачу, свой сеттинг и развивает основную сюжетную линию
- Мир развивается независимо — бездействие имеет последствия

## 3. Как проигрывать музыку

### 3.1. Быстрый старт

```bash
# Персональная волна Яндекса (ваши любимые треки)
python yandex_playlist_player.py --wave

# Плейлист "Мне нравится"
python yandex_playlist_player.py --liked

# Поиск плейлиста по названию
python yandex_playlist_player.py --playlist "Эпичная битва"

# Остановить музыку
python yandex_playlist_player.py --stop
```

### 3.2. Для D&D-сессии (сценарные запросы)

Самый полезный режим — **`--wave`** с описанием настроения. Скрипт сам найдёт подходящую станцию Яндекс.Музыки по ключевым словам на русском.

```bash
# Эпичная битва
python yandex_playlist_player.py --wave "Музыка для DnD битва"
# → mood:aggressive — агрессивная боевая музыка

# Эпическое приключение
python yandex_playlist_player.py --wave "эпичное"
# → mood:epic — эпичная музыка

# Таинственная/мистическая атмосфера
python yandex_playlist_player.py --wave "таинственное"
# → mood:haunting — мистическая музыка

# Грустная/меланхоличная сцена
python yandex_playlist_player.py --wave "грустное"
# → mood:sad — грустная музыка

# Спокойная фоновая музыка для исследования
python yandex_playlist_player.py --wave "спокойное"
# → mood:calm — спокойная музыка
```

### 3.3. Управление во время прослушивания

| Действие                           | Команда / Клавиша                         |
| ---------------------------------- | ----------------------------------------- |
| Пропустить трек                    | **Ctrl+C**                                |
| Выйти из волны                     | **Ctrl+X**                                |
| Остановить музыку (в любом режиме) | `python yandex_playlist_player.py --stop` |

### 3.3.1. Дистанционное управление через `yandex_remote.py`

Можно управлять запущенным плеером из **другого терминала** через скрипт `yandex_remote.py`. Плеер каждые 0.5 сек проверяет файл `.command_queue` на новые команды.

```bash
# В терминале 1: запускаем плеер
python yandex_playlist_player.py --wave

# В терминале 2: меняем плейлист
python yandex_remote.py --playlist "Днд"

# Меняем волну (с темой)
python yandex_remote.py --wave "эпичное"

# Персональная волна
python yandex_remote.py --wave

# Плейлист "Мне нравится"
python yandex_remote.py --liked

# Тишина (остановить mpv, но плеер продолжает ждать команд)
python yandex_remote.py --silence

# Полная остановка и выход
python yandex_remote.py --stop
```

### 3.4. Установка (если делаете впервые)

```bash
# Установить зависимости
pip install yandex-music

# Установить плеер mpv (Windows)
winget install shinchiro.mpv

# Проверить, что работает
python yandex_playlist_player.py --help
```

### 3.5. Настройка токена Яндекс Музыки

1. Получите токен по инструкции: https://github.com/MarshalX/yandex-music-api/discussions/513
2. Создайте файл `.env` в корневой директории проекта с содержимым:
   ```
   YANDEX_MUSIC_TOKEN=ваш_токен_здесь
   ```
3. Файл `.env` автоматически исключается из git (добавлен в `.gitignore`)

> ⚠️ В текущей версии токен уже прописан в `.env` — если вы его не меняли, всё работает из коробки.
